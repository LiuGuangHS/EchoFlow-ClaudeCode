# EchoFlow Code v0.5.3

This release synchronizes upstream desktop, Agent Teams, and runtime improvements while preserving EchoFlow provider, persistence, and desktop release policies.

## New & Improved

- **Agent Teams workbench**: follow team members, tasks, direct messages, reports, and member transcripts from the desktop app without taking over the main workspace.
- **Built-in Agent overrides**: adjust the model and effort for a built-in Agent while retaining its system prompt, tools, and built-in permissions.
- **Live subagent transcripts**: open a running subagent to follow its transcript in real time and resume it without duplicating persisted messages.
- **Chat activity**: completed tool activity is summarized more compactly while active work remains visible.
- **Desktop UX**: improved worktree session details, launch-branch confirmation, image previews, and Agent management controls.

## Compatibility and fixes

- Agent Teams workbench archives are stored under the EchoFlow-owned configuration directory.
- EchoFlow settings and legacy migration behavior remain compatible with existing installations.
- Provider presets remain limited to approved official, local, EchoFlow, and custom integrations.
- Fixed transcript replay handling so legitimate repeated messages are retained and completed subagent output is restored correctly.

## Installation

Download the installer for your platform and architecture from the Assets section at the bottom of this page:

- macOS: `EchoFlow-Code-0.5.3-mac-arm64.dmg` / `EchoFlow-Code-0.5.3-mac-x64.dmg`
- Windows: `EchoFlow-Code-0.5.3-win-x64.exe` / `EchoFlow-Code-0.5.3-win-arm64.exe`
- Linux x64: AppImage, deb, or `EchoFlow-Code-0.5.3-linux-x86_64.rpm`
- Linux ARM64: AppImage, deb, or `EchoFlow-Code-0.5.3-linux-aarch64.rpm`
