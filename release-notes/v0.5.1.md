# EchoFlow Code v0.5.1

这是 EchoFlow Code 桌面端的首个累积发布说明：`v0.1.0` 至 `v0.5.1` 的全部用户可见变更已合并至此文档。下方按主题归类，每个主题下标注该能力首次出现和后续演进的版本号，早期版本中重复出现的同类条目已去重合并。

> 时间跨度 `v0.1.0`（2026-04-18）→ `v0.5.1`（2026-08-02），共 37 个版本。
> 各版本的发布流程说明、验证记录与模板化条目未纳入本文，仅保留与使用者直接相关的内容。

## 桌面工作台与工作区

**右侧工作区与文件面板**
- 新增会话右侧工作区文件面板，可浏览当前项目目录、查看文件树、预览文本文件与本地图片（`v0.1.9`）。早期版本中无变更文件时面板显示为空状态，现已优先展示文件树（`v0.1.9`）。
- 支持查看会话产生的文件变更：新增、修改、删除文件及对应 diff；工作目录不是 Git 仓库时也能基于会话记录与 file-history 快照展示变更（`v0.1.9`、`v0.2.0`）。
- 新增当前轮次变更卡片：每轮回复完成后在聊天流中展示本轮改动，可先审查再决定是否回滚（`v0.1.9`）。
- 文件回滚统一收敛到 checkpoint rewind：回滚目标按对应用户消息定位，减少多轮会话中回错位置；已移除旧的消息 hover rewind 入口，避免两个相近撤销入口并存（`v0.1.9`）。`v0.4.10` 起改用服务端权威 checkpoint，只回退目标轮次，修复异常结束的轮次必须重启后才能撤销的问题（#1030）。
- 支持把工作区文件或局部内容加入聊天：界面显示可读文件 chip，发送给 CLI 的内容保持原生 `@文件路径` 引用；历史会话重载时 transcript 里的 `@文件路径` 会恢复成附件 chip（`v0.1.9`）。
- 面板可向右缩小，不再只能向左拖大（#940，`v0.4.5`）。

**Workbench 与内置浏览器**
- 右侧面板升级为 Workbench，支持 Files / Browser 切换，带地址栏、加载状态、child webview 生命周期和窗口边界同步（`v0.3.2`）。
- 预览与 Open With 链路打通：助手输出、变更文件、workspace 文件、localhost、本地绝对路径、`/preview-fs` 与 `/local-file` 均可走统一预览或 Open With（`v0.3.2`）。
- 网页圈选编辑：支持元素选择、截图、编辑气泡、标注区域和干净的 composer 回填，可将网页局部修改请求直接交给 Agent（`v0.3.2`）。
- 变更文件、workspace 文件与完成消息中的 Open With 菜单入口过重问题已修复，菜单翻转与实际打开编辑器行为已修正（`v0.3.2`）。
- Workbench 面板支持 tab 化展示，workspace、terminal 等面板可在更宽布局中展开（#730，`v0.4.3`）。
- 内置浏览器新增 per-session zoom / scale 控制，缩放同步到 preview bridge、Electron WebContentsView、截图与标注坐标（#952，`v0.4.5`）；高 DPI 下的坐标与交互区域稳定性已修复，缩放控件改为浮在预览区右下角（`v0.4.6`）。
- 预览截图改为 Electron 原生采集，renderer reload 时关闭预览窗口，减少旧窗口与截图状态残留（`v0.4.1`）。

**文件搜索**
- 工作区文件搜索支持直接搜索尚未展开或加载的目录，无需先手动展开目录树；结果可继续预览或加入聊天上下文（#1023，`v0.4.9`）。
- 桌面安装包内置跨平台 ripgrep，为 macOS / Windows / Linux 的 x64 与 ARM64 准备对应二进制，不再要求用户另行安装 `rg`（#923，`v0.4.9`）。
- `@` 文件提及搜索对齐 CLI：改用 git-first 搜索，遵守项目 ignore 规则，减少 `node_modules` 与构建产物噪声；非 git 目录回退到 ripgrep；目录候选与路径显示、插入行为进一步对齐 CLI（`v0.2.6`）。

**终端**
- 新增桌面端真实终端能力，可直接运行宿主机命令，用于安装插件、Skills、MCP 依赖等需要命令行的扩展配置（`v0.1.6`）。
- 终端升级为桌面端标签页工作流，可在标签栏打开并保留多个终端页签；设置页的终端也可新建独立终端标签（`v0.1.8`、`v0.2.0`）。
- 终端页与会话内终端优先在用户当前工作目录打开，提升为独立 tab 后仍保留 cwd（`v0.2.1`）。
- 终端设置支持自定义剪贴板快捷键，减少跨平台复制/粘贴冲突（#837，`v0.4.3`）。
- 隐藏 docked terminal 或提升为 tab 时不再误杀正在输入的 shell；终端页去掉重复 chrome，改善未聚焦时的滚动交互（`v0.3.1`）。
- Windows 用户可配置内置终端的启动 shell / Bash 路径；system fallback、portable Bash path 与显式 startup shell 的优先级更清晰（`v0.2.8`）。
- docked terminal 尺寸不稳定问题已修复（#708，`v0.4.3`）。

**运行位置与工作树**
- 新增仓库启动上下文控制栏：空白聊天 tab 展示仓库路径、分支 / worktree 选择器与一键启动按钮，可在发送首轮消息前指定工作上下文（`v0.2.2`）。
- 分支启动通过 worktree 隔离保护，避免同一工作目录下并发启动不同分支会话产生冲突；worktree 启动模式可在 UI 直接切换（`v0.2.2`）。
- 桌面会话与 CLI worktree 身份对齐：会话 badge 优先从原生 worktree 信息读取，CLI 初始化完成前从 transcript 状态恢复，保证跨重启一致（`v0.2.2`）。
- worktree session 的 desktop chip 隐藏内部分支标签（如 `worktree-desktop-*`）与 slug，仅显示源项目和 worktree 标记；git-info API 区分 launch branch 元数据与实际 checkout 分支（`v0.3.0`）。
- 开始页选择项目目录后立即创建草稿会话，让文件管理、变更视图、运行时选择与终端工具栏在首轮提问前即可用（`v0.1.9`）。

**项目与会话组织**
- 侧边栏按项目 root 组织会话，worktree 会话归并到源项目下；项目排序、隐藏、置顶等偏好持久同步到桌面与 H5（`v0.2.7`）。
- 新增 Open Project 入口，可从当前 session workDir 打开 Finder 或已检测到的本机 IDE，并使用本机应用图标（`v0.2.7`）。
- 侧边栏新增批量管理模式，支持全选、分组选择、Shift 范围选择与删除已选会话；移除了容易误解的按天数快捷清理（`v0.2.6`）。
- 侧边栏宽度可调（240–480px），持久化到 localStorage，双击回到 300px，方向键可微调；设置侧栏从 260px 收到 220px（`v0.5.0`）。
- 全局会话全文搜索：可搜索历史 sessions、消息内容与相关 metadata，并从侧边栏快捷打开结果（`v0.4.3`）。
- 桌面主窗口关闭后继续在托盘后台运行，本地 server 与 adapter sidecar 不因普通关闭窗口而停止；托盘菜单可重新显示窗口或退出应用（`v0.1.9`）。
- 桌面记住主窗口大小、位置与最大化状态，重启后自动恢复，并在外接显示器变化时避免恢复到屏幕外（`v0.1.9`）。
- 应用启动强制单实例，新启动会激活已有窗口（`v0.2.2`）。

## 长会话与消息列表性能

- 长对话切换为基于测量高度的动态虚拟窗口，短对话保持全量挂载；废弃 `content-visibility` 全列表覆盖方案以避免 WebView 白屏（`v0.3.0`）。
- 虚拟滚动 overscan 从动态膨胀（360px → 7200px）改为固定 1200px；移除 scroll-handler 的 `flushSync`，让 React 18 自动批处理接管状态更新（`v0.3.0`）。
- `ResizeObserver` 高度回调改为每帧仅触发一次，而非每个 item 一次全列表重渲染；取消测量反馈的自动滚动，避免与用户滚动冲突（`v0.3.0`）。
- `AssistantMessage`、`UserMessage`、`ToolCallBlock`、`ToolCallGroup`、`ToolResultBlock`、`MarkdownRenderer` 全部加 `React.memo`；per-message 的分支与工具结果查找提升为 `useMemo` Map（`v0.3.0`）。
- Markdown 缓存 key 从完整内容字符串改为 `${len}:${fnv1a}` hash，拆分为 200 条 finalized（8MB）与 4 条 streaming 缓存，streaming 不再驱逐已完成的 parse；VirtualSpacer 改为 ~800px 分片渲染（`v0.3.0`）。
- 新增 `virtualHeightCache`（按 sessionId 的模块级 LRU），切回已访问 session 时复用历史测量高度，跳过 estimate → measure 校正（`v0.3.0`）。
- 实测：797+ 条消息 / 2.6MB 会话从 1–2s 白屏降到 0s 白屏采样，34 个滚动位置全部通过；INP 从 84ms 降到 43ms（`v0.3.0`）。
- 长对话重新挂载后保持阅读位置；虚拟化列表支持可靠搜索、方向导航与当前匹配定位（#1045、#1057，`v0.4.10`）。
- 大历史会话导致侧边栏卡顿的问题已修复：会话列表先按文件修改时间分页，再读取当前页 JSONL，避免一次性解析全部历史（`v0.2.0`）。
- 提升回答进行中手动滚动时的体验：用户向上查看历史消息时，流式输出不再强制把视图拉回底部；停留在底部附近时继续保持自动跟随（`v0.1.7`）。
- 每个 session 保留滚动上下文，暂停自动跟随时显示「跳到底部」按钮（`v0.2.3`）。
- 输入框上方的工具栏改为自然占位，多行输入时不再覆盖 textarea 最后几行（`v0.2.9`）。
- 长 URL 或长 Markdown 链接撑破用户消息气泡的问题已修复（`v0.2.6`）。
- 只含空白字符的 assistant 消息不再渲染成空气泡（`v0.1.9`）。

## 会话与历史

**切分、分支与回退**
- 历史完整 turn 的用户消息与助手消息可直接创建分支会话；分支保留正确的历史链、workdir、worktree 与相关 transcript 元数据（`v0.2.9`）。
- 消息操作栏将复制与分支入口合并为内联控件，减少悬浮按钮遮挡气泡或长文本中跳动（`v0.2.9`）。
- 会话回退（rewind）不只恢复对话状态，也同步恢复对应的文件检查点（`v0.1.6`）。
- rewind 优先按用户消息 ID 精确定位并校验原始内容，修复因隐藏消息或可见索引错位而回退到错误 turn 的问题（`v0.1.8`）。
- rewind 前等待 CLI 退出并排空输出；空 transcript 占位会话仍保留 canonical workDir（`v0.2.1`）。
- 上下文在运行时重启前会完整落盘；恢复历史会话时不再误触发预热（#1033、#1054，`v0.4.10`）。

**上下文与用量统计**
- 新增 `/status`、`/cost`、`/context` 可视化 inspector，在桌面端内展示会话状态、用量与上下文信息，不再只依赖终端文本输出（`v0.1.8`、`v0.2.0`）。
- composer 新增更准确的上下文用量显示，支持活跃 CLI inspection、空会话初始状态、断开会话的 transcript fallback 与模型窗口变化（`v0.2.1`）。
- 上下文统计口径统一：把最新输出 token 纳入下一轮上下文，并用本地估算作为下限，修复 assistant 回复完成后用量反而下降的问题（`v0.2.1`）。
- 上下文 token 用量按模型 context window clamp，修复某些大窗口模型下超过 100% 的显示问题（`v0.2.3`）。
- 上下文占用估算在 Provider 返回空或全零 usage 时不再消失：保留运行模型锚点并回退到本地 transcript 估算，不把估算值误作费用统计（#1063，`v0.4.11`）。
- live session header 计入 cache read/write tokens（#842，`v0.4.4`）。
- 用量统计修复重复计数：Claude Code 按 content block 逐行写 JSONL，每行都重复完整的 `usage` 对象，此前两条统计路径都在累加（`v0.5.0`）。同批修复：成本字段此前是从未赋值的死代码；未知模型不再按 Claude 价格计费；「最长任务」改按 30 分钟以内的间隔累计有效工作时间，不再用首尾时间差（此前实测出现过 436 小时、1137 小时的读数）；workflow 子 agent 的 transcript 此前从未被索引。
- 新增本地 Token usage / Activity 页面，从本地 CLI transcript 汇总 session、message、tool、model token、subagent token 与每日活动（`v0.2.3`）；后续新增历史插件与 Skill 使用排行，并压缩 token summary 展示（`v0.4.2`）。
- Context Compact 成为可读状态：手动或自动 compact 在聊天时间线中显示进行中状态与完成摘要，可展开查看摘要、触发方式、token 与消息数量；并从 transcript 恢复为结构化状态（`v0.2.9`）。
- 修复手动 `/compact` 或自动压缩后上下文百分比仍停在压缩前数值的问题（#743，`v0.4.2`）。
- 新增全局会话全文搜索入口（`v0.4.3`），与本地 SQLite 索引配合（`v0.4.9`）。

**本地索引**
- 新增 `echoflow-code/db/index-v1.sqlite` 派生数据库，覆盖会话元数据与内容、活动统计、定时任务运行记录、团队会话与 Trace；支持增量追加、文件重写识别、删除同步、迁移与损坏恢复（`v0.4.9`）。
- 原始 JSON / JSONL 文件仍是权威数据源；索引不可用时回退到文件读取，可在「设置 → 诊断」中安全重建。重建或删除索引不会删除原始对话、设置、Skills、记忆、定时任务或 Trace 源文件（`v0.4.9`）。
- 诊断页新增本地索引状态面板，可查看构建状态、已索引来源、降级来源、数据库 / WAL 大小、最后更新时间与错误代码（`v0.4.9`）。
- 修复桌面端重启后历史会话仍在源目录但列表未能稳定恢复的问题（#1016，`v0.4.9`）。

**草稿与批量管理**
- 未发送的 prompt 与附件状态在切换标签页、Settings 或 Terminal 后保留，不再跨 tab 互相泄漏或丢失（`v0.2.6`、`v0.2.8`）。
- 切换到其他项目时空会话的 composer draft 不再丢失（#871，`v0.4.4`）。
- 批量关闭 tab 时会确认正在运行的会话，不再静默放弃正在运行的任务（`v0.2.8`）。
- 删除左侧会话列表条目后，右侧对应标签页同步关闭（#80，`v0.1.3`）。
- 修复新建会话未执行、关闭后留下无效 untitled session 的问题（`v0.4.5`）。

- 自定义回答输入框升级为多行编辑器，支持 `Ctrl/Cmd+Enter` 提交（`v0.3.0`）。
- Markdown 渲染支持常见 LaTeX 数学公式，并针对公式密集的长聊天降低 KaTeX 渲染与 DOM 成本（`v0.2.7`）。
- Markdown 渲染阻止 `<style>` 标签与 inline style 注入全局 UI（#904，`v0.4.5`）。
- Skill frontmatter 按结构化行排版，不再被当作 Markdown 渲染成一个巨大的加粗 `<h2>`（`v0.5.0`）。
- Mermaid 大图可读性改善；生成型 flowchart label 含 HTML 换行、花括号或 bracketed type text 时的渲染异常已修复（#803，`v0.4.2`）；label 中斜杠等字符破坏节点形状的问题已修复（`v0.4.7`）。

## 平台与安装

**桌面框架**
- 桌面底层从 Tauri 2 迁移到 Electron（`v0.4.0`）。迁移起因是多位用户反馈桌面端在 macOS 上有明显性能问题、在 Windows 上又有不少行为与开发端 macOS 不一致；根因是 Tauri 在不同平台各自使用系统 WebView（macOS WebKit、Windows WebView2），渲染与交互天然有差异。改用 Electron 自带的 Chromium 作为渲染层以抹平跨平台不一致，代价是安装包体积更大。内置浏览器、Workbench、终端、文件选择、系统通知、托盘、菜单、窗口状态与 sidecar 进程管理全部迁移到新的 Electron 桌面运行时。

# EchoFlow Code v0.5.1

This is the first cumulative release note for the EchoFlow Code desktop client: all user-visible changes from `v0.1.0` through `v0.5.1` have been merged into this document. Entries are grouped by theme; each theme lists the versions in which the capability first appeared and evolved. Duplicate entries across earlier versions have been consolidated.

> Time span: `v0.1.0` (2026-04-18) → `v0.5.1` (2026-08-02), 37 versions.
> Per-version release-process notes, verification records, and boilerplate have been omitted; only content directly relevant to users is retained.

## Desktop Workbench and Workspace

**Right-side workspace and file panel**
- Added a right-side workspace file panel for browsing the project directory, viewing the file tree, and previewing text files and local images (`v0.1.9`). It previously showed an empty state when there were no changes; it now shows the file tree first (`v0.1.9`).
- View changes produced by a session: added, modified, and deleted files with diffs. In non-Git directories, changes are reconstructed from session records and file-history snapshots (`v0.1.9`, `v0.2.0`).
- Added per-turn change cards: after each reply, the turn's changes appear inline in chat so you can review before rolling back (`v0.1.9`).
- File rollback is unified under checkpoint rewind: targets are located by the corresponding user message, and the old hover rewind entry was removed (`v0.1.9`). From `v0.4.10`, an authoritative server-side checkpoint is used and only the target turn is rolled back (#1030).
- Add workspace files or selections to the chat: the UI shows a readable file chip while the CLI still receives a native `@path` reference. On reload, `@path` references in the transcript are restored as attachment chips (`v0.1.9`).
- The workspace panel can now be shrunk to the right instead of only enlarged to the left (#940, `v0.4.5`).

**Workbench and built-in browser**
- The right panel became the Workbench with Files / Browser switching, an address bar, loading state, child webview lifecycle, and window-boundary synchronization (`v0.3.2`).
- Preview and Open With are now unified: assistant output, changed files, workspace files, localhost, absolute local paths, `/preview-fs`, and `/local-file` all route through preview or Open With (`v0.3.2`).
- Web page element selection: element picking, screenshot, edit bubble, annotation area, and clean composer backfill, so a page-local change request can be handed directly to the agent (`v0.3.2`).
- Fixed Open With menus in changed files, workspace files, and completed messages being too heavy, not flipping, or not actually opening the editor (`v0.3.2`).
- Workbench panels can be expanded into tabs for wider layouts (#730, `v0.4.3`).
- The built-in browser gained per-session zoom/scale, synchronized to the preview bridge, Electron `WebContentsView`, screenshots, and annotation coordinates (#952, `v0.4.5`); high-DPI coordinate and hit-area instability was fixed, and the zoom control now floats at the bottom-right of the preview (`v0.4.6`).
- Preview screenshots now use native Electron capture, and preview windows close on renderer reload, reducing stale windows and screenshot state (`v0.4.1`).

**File search**
- Workspace file search now searches directories that have not been expanded or loaded, with results available for preview or adding to chat context (#1023, `v0.4.9`).
- Desktop installers bundle cross-platform ripgrep for macOS, Windows, and Linux on x64 and ARM64, so users no longer need to install `rg` separately (#923, `v0.4.9`).
- `@` file mention search now matches the CLI: git-first search that honors project ignore rules (reducing `node_modules` and build-artifact noise), ripgrep fallback outside Git, and path display/insertion aligned with the CLI (`v0.2.6`).

**Terminal**
- Added a real desktop terminal for running host commands, used for installing plugins, Skills, MCP dependencies, and other command-line extension setup (`v0.1.6`).
- Terminal upgraded to a desktop tab workflow: multiple terminal tabs can be opened and kept in the tab bar, and the Settings terminal can open its own terminal tab (`v0.1.8`, `v0.2.0`).
- Terminal pages and in-session terminals prefer opening in the user's current working directory, and keep the cwd when promoted to a tab (`v0.2.1`).
- Added a configurable clipboard shortcut for the terminal to avoid cross-platform copy/paste conflicts (#837, `v0.4.3`).
- Hiding a docked terminal or promoting it to a tab no longer kills a shell mid-typing; duplicate chrome was removed and unfocused scrolling improved (`v0.3.1`).
- Windows users can configure the built-in terminal's startup shell / Bash path, with clearer precedence between system fallback, portable Bash path, and explicit startup shell (`v0.2.8`).
- Fixed unstable docked terminal sizing (#708, `v0.4.3`).

**Launch location and worktrees**
- Added a repository launch context bar: empty chat tabs show the repository path, branch/worktree selector, and a one-click launch button so the working context is set before the first message (`v0.2.2`).
- Branch launches are protected by worktree isolation, avoiding conflicts when launching different branch sessions in the same working directory. Worktree launch mode can be toggled in the UI (`v0.2.2`).
- Desktop sessions now align with CLI worktree identity: the session badge prefers native worktree info and falls back to transcript state until CLI init completes, staying consistent across restarts (`v0.2.2`).
- Worktree session chips hide internal branch labels (such as `worktree-desktop-*`) and slugs, showing only the source project and worktree marker. The git-info API distinguishes launch branch metadata from the actual checked-out branch (`v0.3.0`).
- Selecting a project directory on the start page immediately creates a draft session, making file management, change views, runtime selection, and the terminal toolbar available before the first message (`v0.1.9`).

**Projects and session organization**
- The sidebar now organizes sessions by project root, with worktree sessions grouped under their source project. Project ordering, hiding, and pinning preferences persist across desktop and H5 (`v0.2.7`).
- Added an Open Project entry to open Finder or a detected local IDE from the current session workDir, using native app icons (`v0.2.7`).
- Added a sidebar batch management mode with select-all, grouped selection, Shift range selection, and delete-selected. The easily-misunderstood "clean up by age" shortcut was removed (`v0.2.6`).
- The sidebar width is adjustable (240–480px), persisted to localStorage, reset to 300px on double-click, and fine-tunable with arrow keys. The settings sidebar narrowed from 260px to 220px (`v0.5.0`).

- Closing the main window keeps the app running in the tray; the local server and adapter sidecars are not stopped by a normal window close. Tray menu can reshow the window or quit (`v0.1.9`).
- The desktop remembers main window size, position, and maximized state, restoring on restart and avoiding off-screen restoration when external displays change (`v0.1.9`).
- The app enforces a single instance; a new launch activates the existing window (`v0.2.2`).

## Long-Session and Message-List Performance

- Markdown cache keys changed from full content strings to `${len}:${fnv1a}` hashes, split into a 200-entry finalized cache (8MB) and a 4-entry streaming cache; streaming no longer evicts completed parses, and VirtualSpacer renders in ~800px chunks (`v0.3.0`).
- Added `virtualHeightCache` (a module-level LRU keyed by sessionId) so returning to a visited session reuses previously measured heights, skipping the estimate → measure pass (`v0.3.0`).

- Long conversations keep their reading position after remount; virtualized lists support reliable search, directional navigation, and current-match location (#1045, #1057, `v0.4.10`).
- Fixed sidebar lag with large session histories: the list pages by file mtime before reading the current page's JSONL instead of parsing all history at once (`v0.2.0`).
- Improved manual scrolling during streaming: scrolling up no longer gets yanked back to the bottom, while staying near the bottom keeps auto-follow (`v0.1.7`).

## Platforms and Installation

**Desktop framework**
- The desktop layer migrated from Tauri 2 to Electron (`v0.4.0`). The migration was driven by user reports of clear macOS performance problems and Windows behaviors diverging from the development-side macOS; the root cause is that Tauri uses each platform's own system WebView (macOS WebKit, Windows WebView2), so rendering and interaction naturally differ. Electron's bundled Chromium is used as the rendering layer to smooth out cross-platform inconsistency, at the cost of a larger installer. The built-in browser, Workbench, terminal, file picker, system notifications, tray, menus, window state, and sidecar process management all moved to the new Electron desktop runtime.

## Installation

Download the installer for your platform and architecture from the Assets section at the bottom of this page:

- macOS: `EchoFlow-Code-0.5.1-mac-arm64.dmg` / `EchoFlow-Code-0.5.1-mac-x64.dmg`
- Windows: `EchoFlow-Code-0.5.1-win-x64.exe` / `EchoFlow-Code-0.5.1-win-arm64.exe`

- Linux ARM64: AppImage, deb, or `EchoFlow-Code-0.5.1-linux-aarch64.rpm`

**macOS**: Double-click the DMG and drag the app into Applications. Properly signed and notarized builds should pass Gatekeeper normally. If you still see "damaged" or "cannot verify developer," use System Settings → Privacy & Security → Open Anyway.

**Windows**: Double-click the `.exe` to install. Run as the current user rather than as administrator. Fully quit the app before an overwrite upgrade; for unsigned builds you can choose "More info" → "Run anyway" at the SmartScreen prompt. The installer checks for data to restore before removing the old version; if it detects a running older app or an unsafe data directory, it preserves the old version and data and asks you to retry.

**Linux**:
```bash
chmod +x EchoFlow-Code-0.5.1-linux-x86_64.AppImage
./EchoFlow-Code-0.5.1-linux-x86_64.AppImage
```
```bash
sudo apt install ./EchoFlow-Code-0.5.1-linux-amd64.deb
```
On ARM64 machines use the corresponding `linux-arm64` / `linux-aarch64` files.
