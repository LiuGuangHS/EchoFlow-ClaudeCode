# EchoFlow Code v0.7.3

本次更新聚焦 **EchoFlow SiHub 浏览器登录**——不用再提前生成系统访问令牌、手工粘用户 ID，点一下登录，在弹出的浏览器窗口里用站点会话直接接管。同时带来 **登出真正断干净**、**凭据失效后的提示不再指错路**，以及下载入口的几处修复。

## EchoFlow SiHub 登录

- **浏览器登录取代手工绑定**：此前要先去控制台生成系统访问令牌，再把用户 ID 与令牌手工粘进面板；用户 ID 抄错、令牌过期是最常见的两个失败原因。现在点「登录 EchoFlow SiHub」会弹出浏览器窗口，在窗口里完成站点登录即可，成功后窗口自动关闭、账户信息回填面板。**不再需要提前生成系统访问令牌。**
- **两条线路各自独立登录**：主站与专线仍然各自登录、凭据互不覆盖，可以各登一个账号再分别建渠道；专线也有自己的登录窗口，不再是共用一个。
- **服务按「EchoFlow SiHub 推荐接入」呈现**：模型列表里的条目改名，宣传文案从「一站式接入」改为「推荐接入」，不再当成官方厂商 API。模型与服务仅在您所在地区法律法规允许的范围内提供，请自行确认所在地的合规要求与可用性。
- **账户入口收进「设置 → 模型配置」**：绑定区域并入模型管理，选好线路页签即可登录、刷新或解绑；解绑只清当前选中线路的账户与本机登录状态，另一条线路不受影响。
- **手工绑定降级为兜底路径**：浏览器登录走不通时仍可手工填写用户 ID 与令牌，文档记为高级用法，不再是主流程。
- **旧的手工绑定账户自动升级**：账户存储带了版本号，此前用系统访问令牌绑定的账户读取时自动迁移到新结构，不必重新绑定一次。
- **改名与登录流程五种语言一并改齐**：简体中文、繁体中文、英语、日语、韩语都换到新文案。

## 登出与凭据失效

- **登出真正断干净**：此前登出只清 Cookie，登录分区的页面存储里还留着令牌，被登出的账号可能在你毫无操作的情况下悄悄登回来。现在登出与被站点拒绝的凭据都会一并清掉页面存储。
- **凭据被拒后直接给重新登录**：此前会继续走一条永远刷不出来的刷新，提示还叫你去更新系统访问令牌——可你走的是浏览器登录，手上根本没有那枚令牌。现在丢弃被拒凭据、重新读账户，界面直接给「登录」按钮。
- **本地桥一时无响应不再误判成拒绝**：此前登录窗口遇到本地服务短暂无响应就直接关掉，看起来像登录被拒。现在这种情况按「等待」处理，窗口留着；真被拒绝才清掉陈旧凭据再关。
- **站点登录页空白时自动重载一次**：站点资源加载完却不绘制时，窗口会一直白屏到登录超时。现在桌面端检测到空白就重载一次。
- **余额为负也能正常读**：站点返回负额度（欠费）时账户会话此前读不出来，现在能正常显示。

## 下载

- **站点页头的下载按钮进下载页**：此前会跳错地方。
- **自定义域名缺元数据时下载仍可用**：不再因为域名下没放元数据就整条下载链路失效。
- **关于页保留手动下载**：自动更新不可用时仍有手动下载入口。
