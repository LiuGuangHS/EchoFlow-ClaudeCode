# EchoFlow Code v0.7.8

本版统一了桌面、CLI 和 IM 的数据根，并修复了登录、会话恢复、工具审批和消息投递中的状态同步问题。

## 数据与升级

- 桌面、CLI 和 IM 共用一个数据根。更换数据目录时，应用在重启阶段核对旧目录归属和写入进程，验证目标数据后才接受新目录。检测到归属不明、冲突或仍有进程写入时会中止迁移。
- 从旧版本升级时，保留桌面偏好、工作区浏览器资料和已安装连接器的标识及注册信息。Windows 安装器会检查迁移恢复状态再清理旧安装文件。
- 「设置 → 数据」支持迁移旧 IM 配置和会话、OpenAI OAuth 凭据以及 WhatsApp 登录。迁移外部数据前，请关闭仍在使用这些文件的应用。目录归并有问题时，请保留原始目录和迁移报告。

## 登录、会话与审批

- 可在桌面供应商设置内登录 EchoFlow。修复了 SiHub 登录、绑定和退出在取消、重复回调及设置页重开时的状态同步问题。
- 修复恢复会话、启动团队成员和运行定时任务时丢失 CLI 选择的问题。定时任务重新发送引导消息时会保留已结束回合的完成状态。
- 桌面、网页、移动端和 IM 会保留待确认的审批决定，等待执行端返回最终状态。修复了 QQ、Slack、企业微信和 WhatsApp 中部分回复、附件与审批重试的状态处理。

## 安装与更新

- macOS 未签名包需要手动下载安装。系统可能提示或阻止启动，Computer Use 在此模式下不可用。签名版须经 Developer ID 签名和 Apple 公证。
- Windows 未签名安装包可能出现 SmartScreen 提示，仍支持应用内更新。Linux 的 AppImage 支持应用内更新，DEB 和 RPM 可手动安装。
- 桌面安装包中的网页端随桌面版更新。Android 对应的移动端版本为 0.1.4，经独立流程交付。
