# EchoFlow Code v0.5.7

本次更新聚焦 **运行时管理与计划执行体验**、**官方账户令牌流程**、**插件市场接口**，并同步升级移动端 Android 工具链与连接体验。

## 当前亮点

### 运行时管理与执行模式

- **运行时管理独立成页**：Claude Code 内置/外部运行时与 DeepSeek Harness 统一放入「设置 → 运行时管理」，状态、启动、停止、重启和更新操作更集中。
- **DeepSeek Harness 入口统一**：旧入口兼容跳转到运行时管理页面，保留独立配置、会话和插件目录的隔离边界。
- **计划审批支持自动模式**：计划执行确认时可以选择自动模式；首次使用会明确请求授权，并沿用既有权限持久化流程。
- **模型选择更稳定**：新会话默认推理强度调整为 medium，并根据模型支持范围和模型默认值选择合适的推理强度；模型选择器补充服务商信息展示。

### EchoFlow 官方账户与令牌

- **按选择读取令牌**：创建 EchoFlow Provider 时，通过服务端的令牌选择接口读取所选令牌的完整 Key，令牌列表仍只展示脱敏预览。
- **失败提示更明确**：令牌读取失败时提示刷新账户后重试，避免创建出不完整的 Provider 配置。

### 插件市场与扩展

- **插件市场查询接口**：新增已注册市场、预设、市场发现和插件详情接口，复用缓存与来源策略校验。
- **来源验证门槛**：市场预设必须经过调用方验证后才能注册，默认不内置未经独立验证的厂商来源。

### 桌面体验与可靠性

- **单实例深链路由**：应用已有实例时，新的 `echoflowcode://` 启动请求会转交给已有窗口处理。
- **敏感 URL 日志脱敏**：深链处理日志不再输出原始 URL。
- **空白会话体验**：更新空白会话引导文案和布局，减少装饰性效果，让输入区更突出。

### Android 移动端

- **原生包名迁移**：Android 原生代码迁移到 EchoFlow 包名目录，保留 WebView、权限会话和连接能力。
- **最近服务器**：移动端保存最多 5 个服务器地址，不保存 H5 Token；凭据仍使用 Android Keystore 加密。
- **二维码与工具链更新**：移除不再需要的相机权限，接入 Google ML Kit 条码扫描依赖，并更新 Android Gradle Plugin、Gradle 与 JDK 构建配置。

## 修复与稳定性

- 修复第二实例启动时深链请求无法传递给已有窗口的问题。
- 修复外部运行时选择和运行时状态入口分散的问题。
- 修复模型切换时推理强度回退不符合模型支持范围的问题。
- 修复 Android 原生目录与移动端 contract test 路径不一致的问题。
