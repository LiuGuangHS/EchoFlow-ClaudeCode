# Claude Code Haha v0.5.5

This is a stability and experience release on top of `v0.5.4`, rounding out native file opening and image editing/rendering, plus streaming and desktop reliability hardening.

## New & Improved

- **Generated files open with native apps** (#1233): files generated or written by the chat can be opened on your machine directly. The open-with menu is now a short, named list — ranked by system default, extension-to-app mapping, install location and usage count, cut to five entries — with working icons, and the file-manager entry is named per platform (#1236).
- **User-attached images are accepted as ImageEdit inputs**: an image you @-mention or paste/drop into the chat can be edited in place. Only session-registered or paste-directory paths are trusted; paths the model finds on its own are still refused.
- **Chat image rendering stabilized**: single-image previews stay readable while multi-image layouts stay compact, assistant output images have one sandboxed rendering owner, and unsafe Markdown images are rejected before the browser can request them.
- **Model-aware default reasoning effort**: the default effort now follows the selected model.
- Tool Search is now opt-in per provider (#1229).

## Fixes

- Truncated tool calls no longer hang the session (#1237): new tool-input duration and stream boundary guards terminate a broken fragment instead of waiting on it forever.
- In a workspace with no git repository and no WorktreeCreate hook, agents that request worktree isolation no longer fail: the run degrades to the shared workspace directory and reports the skip in the workflow log and the Agent tool's result. Explicit entry points (EnterWorktree, `--worktree`, bridge worktree mode) still fail loudly.
- Rewind checkpoints no longer stall on long sessions; the desktop client now recovers safely from sidecar crashes (#1227).
- Generated files are shown once per turn instead of repeating.
- Virtual row measurement is stable (#1223), and H5 sessions no longer leave stale task state behind (#1214).
- The local index coalesces pending reconciliation work instead of rescanning on file-change storms.
- Settings warn when proxy configuration is taken over by an external source (#1219).
- Fixed reported provider and composer problems: cc-switch imports respect the saved `apiKeyField` to pick the right auth header; Anthropic-format providers with experimental betas disabled hide the unavailable effort choice; pasting external rich text preserves line and blank-line boundaries while copied mentions stay mentions.
- Files written by a shell command (e.g. `Write plan.md` plus `python make_report.py`) reach the transcript again; document formats survive the change lookup, bare filenames are anchored to the directory the turn wrote into, and clicking an already-gone path says so instead of doing nothing.
- Quality-gate Windows validation is more stable.

# Claude Code Haha v0.5.5

这是 `v0.5.4` 之后的稳定性与体验更新，重点补齐生成文件的原生打开、图片编辑与渲染体验，并加固流式与桌面端可靠性。

## 新增与改进

- **生成文件可用原生应用打开**（#1233）：聊天中生成或写出的文件可以直接在电脑上打开。「用打开方式」菜单改为按系统默认、扩展名映射、安装位置与使用频率排序的短列表（五项），图标恢复正常显示，文件管理器入口按平台命名（#1236）。
- **用户附带的图片可作为 ImageEdit 输入**：@-mention 或粘贴/拖入聊天中的图片可以直接编辑。仅会话注册或粘贴目录的路径被信任，模型自行发现的路径仍然拒绝。
- **聊天图片渲染稳定**：单图保持可读预览、多图保持紧凑；助手输出图片统一沙箱渲染；不安全的 Markdown 图片在浏览器请求前即被拒绝。
- **模型感知的默认推理强度**：切换模型时默认 effort 跟随该模型。
- Tool Search 改为按 Provider 显式开启（#1229）。

## 修复

- 截断的工具调用不再让会话挂起（#1237）：新增工具输入时长与流式响应边界守卫，损坏的片段会被终止而不是无限等待。
- 非 git 且无 WorktreeCreate hook 的工作区，请求 worktree 隔离的 Agent 不再失败：降级为共享工作目录，并在工作流日志与 Agent 工具结果中报告跳过。显式入口（EnterWorktree、`--worktree`、桥接 worktree 模式）仍然会明确报错。
- 长会话的 rewind 检查点不再停滞；sidecar 崩溃后桌面端可安全恢复（#1227）。
- 生成的文件每回合只显示一次，不再重复出现。
- 虚拟对话的行测量稳定（#1223）；H5 会话不再残留过期任务状态（#1214）。
- 本地索引合并待处理的调和任务，文件变更风暴不再反复扫描。
- 代理配置被外部接管时，设置中会给出明确警告（#1219）。
- 修复报告的 Provider 与 Composer 问题：cc-switch 导入尊重保存的 `apiKeyField`，正确选择鉴权请求头；关闭实验性 betas 的 Anthropic 格式 Provider 隐藏不可用的 effort 选择；粘贴外部富文本保留行与空行边界，复制的提及保持为提及。
- Shell 命令生成的文件（如 `Write plan.md` 加 `python make_report.py`）重新回到会话记录；文档格式通过变更查找保留，裸文件名锚定到回合写入的目录；路径已消失时点击会明确提示，而不再是无声无息。
- Quality-gate 的 Windows 验证更稳定。
