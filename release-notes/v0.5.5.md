# EchoFlow Code v0.5.5

这是 `v0.5.1` 之后的**累积发布**，一次性带来 Computer Use 原生操作重构、Agent Teams 协作工作台、动态 Workflow 编排、统一标签页工作区、连接器入口与更多 IM 平台接入，并修复了其间积累的全部问题。

**建议所有 0.5.x 用户更新**：本版本修复了 Agent Teams 在第三方映射供应商下误用 Claude Opus 4.8 导致费用异常的问题，以及 Windows 安装器在部分环境下挂起、超时的问题。

## 当前亮点

### DeepSeek Harness：在 EchoFlow 里一键装好、跑起来

桌面端新增 **DeepSeek Harness 面板**，把原版 DeepSeek Harness（`@deepseek-ai/dsh`）的安装与运行收进应用内，不需要你自己配环境、开终端。

- **一键安装与更新**：面板内直接安装 DeepSeek Harness，已安装后可「更新 / 重新安装」。安装随运行环境自带，无需手动装 npm 包。
- **完整的生命周期控制**：安装后可直接「启动」；运行中提供「打开 DeepSeek Harness」「重启」「停止」。打开即进入原版界面。
- **状态一目了然**：面板顶部显示当前状态 —— 正在运行 / 已停止 / 未安装 / 运行环境不可用，并显示当前版本号；错误就地提示，不需要翻日志。
- **运行环境自检**：内置运行时要求 Node.js 22.19.0 及以上；不满足时明确报「运行环境不可用」，而不是静默失败。端口按需自动分配，启动带超时保护。
- **数据完全独立**：DeepSeek Harness 的配置、会话和插件数据保存在独立目录，**不会**与 EchoFlow 的服务商、会话、Skills、MCP 或 Agents 自动同步，两边互不干扰（本阶段也不提供插件市场，插件管理能力将单独设计）。

> 说明：DeepSeek Harness 的会话与插件能力保持独立，不接入 EchoFlow 的 Agent Loop。

### 可选择的 Claude Code 运行时

新增运行时选择器，可在「**内置（Bundled）**」与「**已安装（Installed）**」两档 Claude Code CLI 之间切换。

- 默认使用内置运行时，开箱即用；如果本机已有自己的 Claude Code 安装，可切到「已安装」。
- 本机没有可用安装时，「已安装」为禁用状态，并提供「选择已安装运行时」入口，避免切到不可用的运行时。
- 切换过程有明确状态反馈：应用中 / 已应用 / 切换失败；切换请求与实际生效的运行时分别记录，状态变化时界面即时刷新。
- 运行时切换后会话可恢复，工作目录在运行时重启后保留。

### Computer Use：后台操作，不占用你的鼠标键盘


对标 Codex 的后台操作体验，Agent 可以在**后台**点击、输入、滚动和拖拽，你继续用其他应用，互不干扰。

- **原生 macOS 引擎**：直接向目标应用和窗口投递操作，独立的虚拟光标展示 Agent 动作，不干扰你自己的指针。
- **持久化隔离工作进程**：原生操作改由常驻工作进程执行，已知动作可批量连续完成，不再为每个动作等待一次模型往返。
- **遮挡不再失明**：目标窗口被其他应用覆盖时仍能持续获取新画面；窗口移动、缩放、最小化恢复、焦点切换和长任务中的连续输入更加可靠。
- **精确定位**：应用选择显示原生图标并解析真实应用路径；坐标点击走精确的辅助功能命中，辅助功能树中的重复分组与带描述标签控件也可操作。
- **截图证据与受限回传**：截图附带像素尺寸，保留无损采集证据，同时只向模型返回受限尺寸画面；窗口被遮挡层接管后仍保留窗口身份与快照。
- **权限更省心**：取消逐应用授权弹窗，改为启用 Computer Use 时一次全局确认，同时保留全局关闭与目标校验。
- **可取消**：取消操作可贯穿后台进程与锁获取，不再出现取消失效。
- **Windows 同步改进**：输入可靠性、目标校验和虚拟光标一致化，修复取消时的清理问题；**Windows 仍会使用系统鼠标键盘**，后台输入体验为 macOS 独有（需 macOS 14.4+ 与辅助功能 / 屏幕录制权限）。

### Agent Teams：在桌面端看清一支团队

多 Agent 协作团队可以在桌面端**可视化**，且不抢占主工作区。

- **协作工作台**：成员、任务、通信流与依赖泳道画布，实时展示每位成员在做什么。
- **真实状态**：工作台展示真实的成员与任务状态，不再残留过期的「工作中」。
- **实时 transcript**：可打开运行中的 subagent 查看实时记录，恢复运行时不会重复写入已持久化消息。
- **内置 Agent 覆盖**：可调整内置 Agent（Explore、Plan 等）的模型与推理强度，同时保留其系统提示词、工具与内置权限。
- **模型继承修正**：未指定模型的成员跟随主会话当前模型，不再硬编码为 Opus，避免第三方供应商按最贵档位计费。

### 动态 Workflow 编排

模型可以**当场编写并运行编排脚本**，并发或流水线调度多个子代理。运行过程以阶段和所属 Agent 的形式呈现在活动面板，支持暂停、重试与续跑。

### 右侧工作区：统一标签页

工作区从「文件 / 浏览器」两种模式改为**统一的标签页**，文件、浏览器、代码审查、终端可同时打开，隐藏面板或切换任务不再中断其中运行的页面和终端。

- 标签页支持拖拽排序、批量关闭、重新打开已关闭标签；终端可在侧边与底部之间移动而不中断。
- 文件树单击预览、双击固定常驻，同一文件不会重复开标签；输出卡片整行可点，中文文件名不再点击无反应。
- 内置浏览器菜单改为系统原生弹窗，打开时网页保持可见；地址栏支持历史建议，新窗口链接在当前任务内开成后台标签。
- 终端配色跟随当前主题，浅色主题下不再是黑底。
- 代码审查改为显式两侧比较，支持暂存文件与区块，还原改动前先保存副本。
- 重启应用后标签恢复，终端以「已退出」状态回来并可手动重启。

### 连接器与技能

把飞书、钉钉、企业微信、Notion、GitHub、高德等 **54 个第三方服务** 收进统一的安装与授权入口。

- 新增「技能 · 连接器」页面，安装、停用、移除都在同一处；未连接账号前不会把能力挂到会话上。
- `@` 与 `/` 都能引用插件和技能；会话已打开时安装并连接，当前会话会即时刷新出它的技能与工具。
- 技能标签页恢复为纯粹的市场列表，移除了上层的「精选技能」一栏。

### 更多 IM 平台，更简单的接入

- **飞书扫码创建机器人**：手机确认即可创建新机器人并自动保存凭据，保留已有机器人配置，支持国际版 Lark。
- **新增企业微信、QQ 和 Slack 适配器**：均使用长连接，无需公网回调地址，支持私聊配对、会话恢复、工具权限与附件。
- **IM 恢复项目会话历史**：各适配器共享项目与会话选择，恢复失败时保留原有绑定，并与桌面端同步权限。
- **IM 渠道访问其他项目**：Telegram / 飞书 / 微信 / 钉钉 / WhatsApp 可在允许目录范围内访问其他项目。
- **Telegram 完善**：会话恢复、Provider / 模型切换、Skills 调用、权限确认与图片回传。

### 远程访问

- **ngrok 公网访问**：在「设置 → H5 访问」填入 Authtoken 即可开启。
- **设备配对**：桌面生成一次性二维码，手机扫码后需在桌面允许；已配对设备可随时撤销，结果重启后保留。
- 手机端只开放「模型供应商」与「通用配置」，API Key 不会回显；桌面管理、工作区、终端仍只能在桌面操作。

### 模型与 Provider

- **Provider 请求兼容设置**：服务商编辑中新增「回复输出预算」与「高级兼容设置」，可设置普通回复最大输出 token、已知端点输出上限、输出 token 参数字段，以及采样参数、推理参数、并行工具调用、结构化输出四项能力开关（仅对 OpenAI 兼容格式显示；配置的预算不再被模型名推断出的上限压回默认值）。
- **新增 Fable 5.1**：加入官方模型目录与服务端兜底列表，支持 low / medium / high / xhigh / max 推理强度（默认 high）。
- **Grok 官方默认升级为 grok-4.6**，支持 xhigh 推理强度。
- **ApiSmart 接入**：作为图片生成后端。
- **API 域名迁移**：主站迁移至 `api.echoflowai.cc`，并新增专用线路端点，可在界面中切换并持久化偏好。
- **模型目录缓存优先**：Provider 不可达时不再阻塞桌面端启动；支持从 cc-switch 一键导入 Claude Code Provider，并从 OpenAI 兼容接口获取模型列表。
- **模型选择器支持搜索**，快速定位目标模型；未配置模型时引导用户完成设置。
- **模型感知的默认推理强度**：切换模型时默认 effort 跟随该模型。
- **工具调用参数**：可选参数的工具改为显式非严格 schema，不再因为缺少可选字段而丢失参数。
- 保留 Provider 的 1M 上下文标记与显式能力开关，跨上下文别名时能力识别不再丢失。

### 会话与历史

- **会话记录默认保留 365 天**，可在「设置 → 通用」修改；修改时预览将被清理的文件数量并要求确认（方案、文件历史、调试日志、粘贴内容、工作树仍保持 30 天）。
- **桌面端完整历史浏览**：侧边栏近期列表之外的历史会话仍可访问，仅在打开时加载，并支持按项目滚动加载更早会话。
- **侧边栏任务视图**：从按项目分组切换为平铺任务列表，运行中任务优先展示，其余按自然日归组；每项显示所属工作区，等待授权的任务有独立状态标识。
- **增强 Trace 追踪视图**：查看起始系统提示词和工具列表，区分注入上下文与用户消息，直接浏览工具输入和 Token 用量；完善 OpenAI Responses 请求与截断请求预览的解析。
- **仅回退对话**：纯聊天或失败的回合也能回退，不恢复磁盘文件，没有文件检查点时同样可用；替换回合后的检查点范围也已修正。
- **多问题提问导航**：一次提出多个问题时顶部出现题号页签，单选后自动跳到下一题，全部答完才能提交。
- **上下文用量面板**：新增「此次会话」区块，显示总 token、缓存命中率与生成速度。
- **对话记录折叠**：工具活动折叠为紧凑摘要，不再每个工具调用一张卡。

### 桌面体验

- **生成文件可用原生应用打开**：聊天中生成或写出的文件可直接在电脑上打开；「用打开方式」为按系统默认、扩展名映射、安装位置与使用频率排序的五项短列表，图标正常显示，文件管理器入口按平台命名。
- **附件图片可编辑**：@-mention 或粘贴/拖入的图片可作为 ImageEdit 输入（仅信任会话注册或粘贴目录路径，模型自行发现的路径仍拒绝）。
- **聊天图片渲染稳定**：单图保持可读预览、多图保持紧凑，助手输出图片统一沙箱渲染，不安全的 Markdown 图片在浏览器请求前即被拒绝。
- **AI 请求超时**：默认由 10 分钟改为 30 分钟，上限不再被截断；流式回复总时长上限随超时同步放宽（不低于 600 秒），已运行会话修改后立即生效。
- **计划模式审批携带权限模式**：新增「批准并自动接受编辑」与「批准并跳过权限」，批准时显式固定实施阶段权限模式。
- **Slash 命令分组**：按用途分组，运行位置选择、发送按钮、会话标签与设置侧栏交互进一步简化。
- **设置重组**：「供应商」更名为「模型配置 / 模型管理」；「通用」恢复 Agent Teams 开关。
- **回复可点击**：回复中的 URL 和文件路径可直接点击；Shell 工具卡显示输出，完成的对话显示结束时间与耗时。
- **AskUserQuestion** 新增「再聊一下」入口，并自动识别、记住系统显示语言。
- **批量元素选择**：支持批量选择元素。

## 修复

### 稳定性与正确性

- **Agent Teams 误用模型**：未指定模型的成员不再硬编码为 Claude Opus 4.8，改为跟随主会话模型，避免第三方映射供应商按最贵档位计费；在 `/config` 中显式固定的成员模型仍然优先。
- **撤销功能恢复**：修复白名单之外的工具会让整段回退失效、撤销实际不可用的问题；现在会还原已跟踪文件并对其余部分给出提示。
- **截断的工具调用不再挂起**：新增工具输入时长与流式响应边界守卫，损坏的片段会被终止而不是无限等待；改为检测流是否停滞，持续收到有效参数时不再按总耗时误终止。
- **MCP 连接竞态**：关闭与重连不再互相覆盖，禁用状态在在途重连结果返回后仍然生效，连接清理逻辑统一。
- **MCP 项目作用域**：桌面设置中的 MCP Server 现在会尊重项目作用域，项目级 MCP Server 重启后不再消失。
- **工具结果中的媒体丢失**：跨 Provider 与 MCP 路径保留工具结果里的图片等媒体。
- **运行中丢失聊天历史**：实时更新时保留已持久化的历史，流式重试清理在历史恢复后重新对齐。
- **运行时配置错误后历史丢失**：将配置选择被拒绝视为非终止错误，仅存在配置错误时恢复完整记录。
- **OpenAI 协议收尾与输出预算契约**：Chat 与 Responses 两条流式路径按事件边界完整解析 SSE，正确处理结束事件与不完整流，避免回复被提前结束或截断；请求本身不合法时返回 `invalid_request_error` 而不是 502。
- **sidecar 崩溃恢复**：长会话 rewind 检查点不再停滞，桌面端可从中安全恢复。
- **本地索引**：空或仍在构建时不再回退到全量扫描 JSONL；合并待处理的调和任务，文件变更风暴不再反复扫描。
- **工作目录**在运行时重启后保留；创建会话后保留所选项目目录。
- **活动摘要**按唯一文件统计修改数量；缓存 Token 统计说明更清晰。
- **工作台真实状态**：展示真实的成员与任务状态，不再残留过期的「工作中」。

### Provider 与模型

- **GPT 中转推理强度丢失**：通过兼容 Provider 请求时正确传递所选推理强度。
- **DeepSeek 推理内容回传报错**：为 OpenAI 兼容中转后的 DeepSeek 保留 `reasoning_content`，修复缺少推理内容导致的 400 错误；并修复 OpenAI Chat 转发中丢失 DeepSeek 图片输入的问题。
- **GLM 5.3 / GLM-5.3-Flash 兼容**：补齐模型推理能力识别，发送匹配的思考参数，修复报告中的 1210 错误。
- **兼容 Provider 丢失 Computer Use 截图**：修复 OpenAI Chat 代理转换丢弃工具结果图片块的问题，让支持视觉的模型收到截图。
- **Anthropic 兼容端点重复 `/v1`**：在 Anthropic 请求边界归一化 API 版本，保留网关前缀与已保存的 Provider 设置。
- **小型上下文模型被钉在 1M**：修复导致自动压缩永不触发的问题。
- **Grok xhigh 被钳制**：修复强度被降为 high、live-catalog 模型强度滑块回弹的问题；切换模型后剥离受保护的思维内容。
- **MiniMax 区域化端点**匹配。
- **cc-switch 导入**尊重保存的 `apiKeyField`，正确选择鉴权请求头。
- **Anthropic 格式 Provider** 在关闭实验性 betas 时隐藏不可用的 effort 选择。
- **Fork 会话令牌用量**重复计数修复。
- 按模型能力归一化推理强度设置。

### 桌面端

- **图片被模型拒绝不再污染会话**：给不支持视觉的模型发图后，后续纯文本轮次不再重复同一个 400。
- **恢复会话后旧文件误报**：不再把上一轮文件改动带到之后只聊天的回合；「本轮更改」卡片默认折叠，展开状态在滚动和列表重建后保持，键盘焦点正确回到展开按钮。
- **窗口拖拽**：恢复侧边栏和工作区顶栏空白区域的窗口拖动。
- **会话列表加载**：本地索引为空或仍在构建时不再长时间卡住，打开侧边栏或 Trace 页不再卡顿。
- **输入框**：上下文用量改为紧凑环形指示，不再挤占输入框；短项目列表不再显示多余折叠按钮。
- **模型配置**：连通性测试返回的长错误不再把按钮挤成两行。
- **空改动卡片**：没有任何文件改动的回合不再显示「0 个文件已更改」。
- **命令行菜单清理**：`/` 菜单不再列出桌面端跑不通的命令。
- **提交与 PR 不再自动署名**：移除提交信息与 PR 描述中的 `Co-Authored-By` 和 "Generated with Claude Code"（`attribution` / `includeCoAuthoredBy` 作为兼容字段保留）。
- **图片位置**：保留本地图片在 Markdown 正文中的原始位置，不再统一提取到末尾。
- **限流重试提示**：明确显示用量或速率限制原因，用易读时长替代大量秒数。
- **Telegram 回复不完整**：保留完整流式回复，并修复遇到限流后的消息投递恢复。
- **工作区 Markdown 预览**现在能显示图片。
- **工具生成的媒体**（如 Bash 渲染的图片）在回合没有跟踪文件变更时不再消失；生成的文件每回合只显示一次。
- **Shell 命令生成的文件**重新回到会话记录；文档格式通过变更查找保留，裸文件名锚定到回合写入的目录；路径已消失时点击会明确提示。
- **虚拟对话行测量稳定**；H5 会话不再残留过期任务状态；H5 在工具流完成前即显示 AskUserQuestion 卡片。
- **界面细节**：修复打开工作区后窗口右上角出现灰色凹槽、顶栏多种标签被挤压、项目菜单被浏览器预览遮挡、模型选择器表头滚动穿透、活动面板跨标签页保持、SubAgent 工具卡展开状态保持、worktree 路径与未加载会话的标签页清理、Windows 宠物与聊天渲染、打包版连接器与技能品牌图标无法加载等问题。
- **SubAgent 任务**不再混入主会话的活动面板与任务列表；运行中的子 Agent 详情页不再空白。
- **粘贴外部富文本**保留行与空行边界，复制的提及保持为提及。
- **代理配置**被外部接管时，设置中会给出明确警告。

### 安装器与发布（Windows）

- **移除有缺陷的 `NtQueryInformationProcess` 调用**：该实现的 `System::Call` 语法错误会导致安装器在 `customCheckAppRunning` 阶段挂起，CI 出现 180 秒超时；现回退为返回安装器自身 PID 的简单实现，满足排除安装器自身的实际用途。

# EchoFlow Code v0.5.5

This is a **cumulative release** on top of `v0.5.1`, bringing the rebuilt Computer Use, the Agent Teams workbench, dynamic Workflow orchestration, a unified tabbed workspace, a single connector surface and more chat-platform adapters in one update, together with every fix accumulated in between.

**Everyone on 0.5.x should update**: this release fixes Agent Teams picking a hardcoded Claude Opus 4.8 under mapped third-party providers (which could be billed at the most expensive tier), and Windows installers hanging or timing out in some environments.

## Current highlights

### DeepSeek Harness: installed and running from inside EchoFlow

A new **DeepSeek Harness panel** in the desktop app brings the official DeepSeek Harness (`@deepseek-ai/dsh`) install and run flow into the app, so you no longer configure an environment or open a terminal yourself.

- **One-click install and update**: install DeepSeek Harness right from the panel, then use "Update / Reinstall" once it is present. The runtime ships with the app, so there is no manual npm step.
- **Full lifecycle control**: "Start" once installed, and while it runs you get "Open DeepSeek Harness", "Restart" and "Stop". Opening it lands you in the original interface.
- **Status at a glance**: the panel header shows Running / Stopped / Not installed / Runtime unavailable plus the current version, and errors surface in place instead of hiding in a log.
- **Runtime self-check**: the bundled runtime requires Node.js 22.19.0 or newer and reports "runtime unavailable" clearly when that is not met, rather than failing silently. Ports are allocated on demand and startup is protected by a timeout.
- **Fully separate data**: DeepSeek Harness keeps its configuration, sessions and plugin data in its own directory and does **not** sync with EchoFlow's providers, sessions, skills, MCP servers or agents. No plugin market is offered at this stage; plugin management will be designed separately.

> Note: DeepSeek Harness keeps its own sessions and plugin capabilities and is not wired into EchoFlow's agent loop.

### Selectable Claude Code runtime

A new runtime selector switches the Claude Code CLI between **Bundled** and **Installed**.

- The bundled runtime is the default and works out of the box; if your machine already has its own Claude Code install, you can switch to "Installed".
- When no usable install exists, "Installed" is disabled and a "Choose installed runtime" entry is offered, so you cannot switch to a runtime that is not there.
- Switching reports its state clearly — applying, applied, or failed — with the requested and effective runtimes tracked separately and the UI refreshing as the state changes.
- Sessions recover across a runtime switch, and the working directory survives a runtime restart.

### Computer Use: background operation without taking over your input

Taking Codex's background-operation experience as the reference, the agent can click, type, scroll and drag **in the background** while you keep working in other apps.

- **Native macOS engine** delivers input to the target app and window, with a virtual cursor that shows the agent's actions independently of your own pointer.
- **Persistent isolated worker**: native actions run in a long-lived worker process, so known operations are batched without a model round trip between each input.
- **Occlusion-proof capture**: background window capture stays fresh when another app covers the target; window movement, resizing, minimized targets, focus changes and repeated text entry during long tasks are handled more reliably.
- **Precise targeting**: app selection shows native icons and resolves the exact app bundle; coordinate clicks route through the exact accessibility hit, and controls with duplicate groups or descriptive labels remain actionable.
- **Evidence with bounded payloads**: screenshots carry pixel dimensions and keep lossless capture evidence while returning bounded images to the model; window identity and snapshots survive overlay takeover.
- **Simpler permissions**: repeated per-app prompts are replaced by a single feature-wide consent when Computer Use is enabled, keeping global disablement and target validation.
- **Cancellable**: cancellation propagates through the worker and lock acquisition instead of silently failing.
- **Windows** also gains more reliable input handling, target validation and a consistent virtual cursor, with cancellation cleanup fixed; **Windows still shares the system mouse and keyboard**. The background-input experience above is macOS-only (requires macOS 14.4+ plus Accessibility / Screen Recording permissions).

### Agent Teams: see a whole team from the desktop

Multi-agent teams are visualized in the desktop app without taking over the main workspace.

- **Workbench**: members, tasks, a communication feed, and a dependency-lane canvas showing what each member is doing in real time.
- **Real state**: the workbench reports real member and task state instead of stale "working" statuses.
- **Live transcripts**: open a running subagent to follow its transcript in real time and resume it without duplicating persisted messages.
- **Built-in Agent overrides**: adjust the model and effort for a built-in Agent while retaining its system prompt, tools and built-in permissions.
- **Model inheritance fixed**: members without a model follow the lead session's current model instead of a hardcoded Opus, avoiding the most expensive tier under third-party providers.

### Dynamic Workflow orchestration

The model writes and runs orchestration scripts on the fly, driving subagents concurrently or in pipelines. Runs show in the activity panel as phases with their agents, and can be paused, retried, or resumed.

### Workspace: unified tabs

The workspace is no longer a two-mode files/browser panel but a **unified set of tabs**: files, browser pages, code review and terminals can all be open at once, and hiding the panel or switching tasks no longer interrupts the pages and terminals running inside.

- Drag to reorder, close in bulk, or reopen a closed tab; terminals move between the side and bottom panels without interruption.
- Single-click opens a file preview and double-click pins it, with no duplicate tabs for the same file; the whole output card is clickable, and CJK filenames no longer fail silently.
- The built-in browser menu is a native popup so the page stays visible while open, the address bar offers history suggestions, and new-window links become background tabs inside the current task.
- Terminal colors follow the active theme, so light themes no longer get a black terminal.
- Code review offers explicit two-sided comparisons with file and hunk staging, saving a recoverable copy before any discard.
- Tabs come back after a restart, with terminals exited and restartable.

### Connectors and skills

Brings **54 third-party services** — Feishu, DingTalk, WeCom, Notion, GitHub, Amap and more — into one install-and-authorize surface.

- A new "Skills · Connectors" page keeps install, deactivate and remove in one place, and never attaches a capability to a session before its account is connected.
- Both `@` and `/` reference plugins and skills, and installing and connecting one while a chat is open refreshes that chat's skills and tools immediately.
- The skills tab is a plain market list again, with the curated "Featured skills" row removed.

### More chat platforms, with less setup

- **Create a Feishu bot by scanning a QR code**: authorize on your phone and the new bot's credentials are saved automatically, keeping existing bot configurations and supporting international Lark tenants.
- **New WeCom, QQ and Slack adapters** use persistent connections without a public callback URL, and support private chats with pairing, session recovery, tool permissions and attachments.
- **IM project session history**: adapters share project and session selection, keep bindings on failed restoration, and sync permissions with desktop clients.
- **IM channels reach other projects**: Telegram / Feishu / WeChat / DingTalk / WhatsApp can reach other projects within an allowed-roots boundary.
- **Telegram**: session recovery, provider and model switching, skill invocation, permission confirmation and image delivery.

### Remote access

- **ngrok public access**: enter an authtoken under Settings → H5 Access to enable it.
- **Device pairing**: the desktop shows a one-time QR code and the phone must be approved on the desktop; pairings can be revoked and survive a restart.
- The phone exposes only "Model providers" and "General" settings, and API keys are never echoed back; desktop administration, the workspace and terminals remain desktop-only.

### Models & providers

- **Provider request compatibility settings**: a "reply output budget" field and advanced compatibility options for the endpoint output limit, the output token field, and switches for sampling parameters, reasoning parameters, parallel tool calls and structured output (OpenAI-compatible formats only; a configured budget is no longer clamped back to the model-family default).
- **Fable 5.1**: added to the official catalog and server fallback list with low / medium / high / xhigh / max reasoning effort (default high).
- **Grok Official now defaults to grok-4.6**, with xhigh reasoning effort.
- **ApiSmart** joins as an image-generation backend.
- **API domain migration**: the main site moves to `api.echoflowai.cc` with an additional dedicated-line endpoint, selectable in the UI with a persisted preference.
- **Cache-first model catalog**: an unreachable provider no longer blocks desktop startup; cc-switch import and OpenAI-compatible model listing are supported.
- **Model selector search**, plus setup guidance when no model is configured yet.
- **Model-aware default reasoning effort**: the default effort follows the selected model.
- **Tool payloads**: tools with optional arguments use explicit non-strict schemas, so optional fields are no longer dropped.
- Provider 1M context markers and explicit capability opt-outs are preserved across context aliases.

### Sessions & history

- **Transcripts are kept for 365 days by default**, configurable in Settings → General, where a change previews the files to be removed and asks for confirmation (plans, file history, debug logs, pastes and worktrees keep the 30-day window).
- **Full desktop history browsing**: conversations beyond the recent sidebar list stay reachable, hydrate only when opened, and older sessions load while scrolling within projects.
- **Task view in the sidebar**: a flat list with running sessions first and the rest grouped by calendar day, each showing its workspace, plus a distinct status indicator for tasks waiting for permission.
- **Expanded Trace view**: inspect the opening system prompt and tool catalog from the session overview, distinguish injected context from your messages, and scan tool inputs and token counts, with more faithful OpenAI Responses parsing.
- **Conversation-only rewind**: roll back pure-chat or failed turns without restoring files, including when no file checkpoint is available; replacement turns now use the correct checkpoint scope.
- **Next-question navigation**: a multi-question prompt shows question tabs, advances on single-select, and enables Submit only once every question is answered.
- **Context usage panel**: a new "This session" block shows total tokens, cache hit rate and generation speed.
- **Transcript folding**: tool activity folds into a compact summary instead of one card per tool call.

### Desktop experience

- **Generated files open with native apps**: files written by the chat open on your machine directly, with a short, named open-with list ranked by system default, extension mapping, install location and usage count, working icons, and a platform-named file-manager entry.
- **Attached images are accepted as ImageEdit inputs** (only session-registered or paste-directory paths are trusted; paths the model finds on its own are still refused).
- **Chat image rendering stabilized**: readable single-image previews, compact multi-image layouts, one sandboxed rendering owner for assistant output, and unsafe Markdown images rejected before the browser can request them.
- **AI request timeout** moves from 10 minutes to 30 minutes by default with no clamp, and the overall stream duration cap scales with it (never below 600s), taking effect immediately in running sessions.
- **Plan approval carries a permission mode**: "Approve & auto-accept edits" and "Approve & bypass permissions" mirror the official terminal and pin the implementation-phase permission mode.
- **Grouped slash commands**, with simplified run-location selection, send button, session tabs and settings sidebar.
- **Settings**: "Providers" is renamed to "Model Settings / Model Management", and an Agent Teams switch returns to Settings → General.
- **Clickable output**: URLs and file paths in replies are clickable, shell tool cards show output, and completed conversations show end time and duration.
- **AskUserQuestion** gains a "chat more" entry point, and the system display language is detected and remembered.
- **Batch element selection** is supported.

## Fixes

### Stability and correctness

- **Agent Teams picking the wrong model**: members without a model follow the lead session's model instead of a hardcoded Claude Opus 4.8, avoiding the most expensive tier under mapped providers, while a model explicitly pinned in `/config` still wins.
- **Undo restored**: a tool outside a small allowlist previously disabled rewind for the whole range; undo now restores tracked files and warns about the rest.
- **Truncated tool calls no longer hang the session**: tool-input duration and stream boundary guards terminate a broken fragment, and stalled-progress detection replaces fixed-duration aborts.
- **MCP connection races**: close and reconnect no longer overwrite each other, the disabled state survives in-flight reconnect results, and connection cleanup is unified.
- **MCP project scope**: desktop MCP servers now respect project scope and no longer disappear after a restart.
- **Media in tool results**: images and other media are preserved across provider and MCP paths.
- **Chat history lost while tasks run**: durable history is preserved during live updates and stream retry cleanup is rebased after hydration.
- **History lost after runtime config errors**: rejected runtime selections are treated as non-terminal errors, restoring the full transcript.
- **OpenAI protocol termination and output budgets**: both Chat and Responses streaming paths parse SSE by event boundary, handle terminal events and incomplete streams, and no longer end or truncate a response early; invalid requests return `invalid_request_error` instead of a 502.
- **Sidecar crash recovery**: rewind checkpoints no longer stall on long sessions.
- **Local index**: no fallback to scanning every JSONL when the index is empty or still building, and pending reconciliation work is coalesced instead of rescanning on file-change storms.
- **Working directory preserved** across runtime restarts, and the selected project directory is kept after creating a session.
- **Activity summaries** count unique edited files, and cached-token accounting is clearer.
- **Real workbench state** replaces stale "working" statuses.

### Providers and models

- **GPT relay reasoning effort**: preserve the selected effort through compatible providers.
- **DeepSeek reasoning round trips**: preserve `reasoning_content` behind OpenAI-compatible relays (fixing missing-reasoning 400s), and stop dropping DeepSeek image inputs.
- **GLM 5.3 / GLM-5.3-Flash compatibility**: recognize reasoning capabilities and send compatible thinking parameters, fixing the reported 1210 errors.
- **Computer Use screenshots through compatible providers**: preserve tool-result image blocks so vision-capable models receive the screenshots.
- **Duplicate `/v1` in compatible endpoints**: normalize the API version at Anthropic request boundaries while preserving gateway prefixes and saved provider settings.
- **Small-context models pinned at 1M**, which prevented auto-compact from ever firing.
- **Grok xhigh clamped to high** and the effort slider snapping back for live-catalog models; protected thinking is stripped after switching models.
- **MiniMax regional API endpoints** matched.
- **cc-switch imports** respect the saved `apiKeyField` to pick the right auth header.
- **Anthropic-format providers** with experimental betas disabled hide the unavailable effort choice.
- **Fork token usage** double-counting fixed.
- Reasoning effort is normalized by model capability.

### Desktop

- **Image rejections no longer poison a session**: later text-only turns no longer repeat the same 400 after sending an image to a model without vision.
- **Stale files after resuming a session**: an earlier turn's changes are no longer carried into later chat-only turns, change cards default to collapsed, the expanded state survives scrolling and list remounts, and keyboard focus returns to the disclosure button.
- **Window dragging** on the sidebar and workspace headers is restored.
- **Session list loading** no longer hangs when the local index is empty or still building, so opening the sidebar or Trace page is responsive.
- **Composer**: context usage becomes a compact ring instead of eating the input width, and short project lists no longer show a fold button.
- **Model settings**: long connection-test errors no longer squash the button into two lines.
- **Empty change cards**: a turn with no file changes no longer shows a "0 files changed" card.
- **Slash menu cleanup**: the `/` menu no longer lists commands the desktop cannot run.
- **No automatic attribution in commits and PRs**: `Co-Authored-By` and "Generated with Claude Code" are no longer injected (`attribution` / `includeCoAuthoredBy` remain accepted compatibility fields).
- **Images moved out of the reply body**: local images keep their original Markdown positions instead of being collected at the end.
- **Rate-limit retries** explain usage or rate limits explicitly with readable wait times.
- **Telegram incomplete replies** retain complete streamed replies and recover delivery after rate limiting.
- **Workspace Markdown previews** now render images.
- **Tool-generated media** (e.g. images rendered via Bash) no longer disappears when the turn has no tracked file changes, and generated files are shown once per turn.
- **Files written by a shell command** reach the transcript again, document formats survive the change lookup, bare filenames anchor to the directory the turn wrote into, and clicking an already-gone path says so instead of doing nothing.
- **Stable virtual row measurement**; H5 sessions leave no stale task state behind; H5 shows AskUserQuestion cards before the tool stream completes.
- **Interface details**: fixes the grey notch in the window's top-right corner once the workspace is open, squeezed header tabs, the project menu being covered by the browser preview, model selector header scroll bleed-through, activity panel state across tab switches, SubAgent tool card expand state across live refresh, worktree paths and unloaded-session tab cleanup, Windows pet and chat rendering, and packaged connector and skill icons failing to load.
- **SubAgent tasks** no longer leak into the main session's activity panel or task list, and a running subagent's detail page is no longer blank.
- **Pasted external rich text** preserves line and blank-line boundaries, and copied mentions stay mentions.
- **Proxy configuration** taken over by an external source now warns clearly in settings.

### Installer and release (Windows)

- **Removed the buggy `NtQueryInformationProcess` call**: its incorrect `System::Call` syntax hung the installer during `customCheckAppRunning`, causing 180s CI timeouts; it now returns the installer's own PID as the parent PID, which satisfies the actual exclusion use case.
- **Removed the OpenConsole.exe fallback match** to avoid false positives with Windows Terminal's system process, with the smoke test updated to match.
- **Restored upstream build scripts** to eliminate the custom `getProcessInfo.nsh` parent-PID logic and its hang points, keeping only EchoFlow branding.
- **Fixed a CSV filename inconsistency** in the fallback process check.
- **Unsigned Windows releases** are allowed in production while SignPath approval is pending; macOS builds are signed and notarized.
- **CI**: GitHub Actions upgraded for Node.js 24, and the Dependabot config incompatible with the Bun lockfile was removed.
- **Built-in updates** no longer trip the installer legacy-data guard.
- **Quality-gate Windows validation** is more stable.
