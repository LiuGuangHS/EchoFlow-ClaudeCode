# Support / 支持

## Get help / 获取帮助

1. Start with the [documentation](https://code.echoflow.cn), especially installation, model setup, first session, and troubleshooting.
2. Search existing Issues and Discussions before opening a new thread.
3. Use a question for setup or usage help, a bug report for reproducible product failures, and a feature request for a concrete product need.

1. 先查阅[文档](https://code.echoflow.cn)，尤其是安装、模型配置、第一条会话和故障排查。
2. 新建内容前先搜索已有 Issues 和 Discussions。
3. 配置和使用问题使用咨询模板；可复现的产品故障使用 Bug 模板；明确产品需求使用功能建议模板。

## Keep reports safe / 安全提交

Do not post API keys, tokens, cookies, OAuth files, private project paths, or unreviewed diagnostics exports. For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

不要提交 API Key、Token、Cookie、OAuth 文件、私有项目路径或未经审查的诊断导出。安全漏洞请遵循 [SECURITY.md](SECURITY.md)，不要创建公开 Issue。
