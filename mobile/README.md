# EchoFlow Code 移动端

本目录是 iOS、Android 与 H5 共用的 Expo 应用；手机负责提醒、决定、派发任务和查看结果，执行与配置保留在电脑上。

开发、构建、连接、通知及已有验收记录集中在[移动端维护资料](../docs/_internal/mobile-maintenance.md#mobile-overview)。原记录中的日期、验证范围与未完成项均保留，不代表本次重新验收。

## 单一移动端实现

旧 WebView 壳的行为对照与身份迁移边界见[单一移动端实现](../docs/_internal/mobile-maintenance.md#单一移动端实现)。本目录保留唯一 Expo 应用入口，不恢复旧壳或旧发版链路。
