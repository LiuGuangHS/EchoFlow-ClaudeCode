# 登录 EchoFlow SiHub

EchoFlow SiHub 是 EchoFlow 的推荐接入服务。登录之后，你不需要自己申请各家厂商的密钥，选一个调用令牌就能建好一条模型渠道。

如果你用的是别的服务商，看 [连接模型服务](./models.md)。这一页只讲 EchoFlow SiHub。

> 模型与服务仅在您所在地区法律法规允许的范围内提供，请自行确认所在地的合规要求与可用性。

## 前置条件

- 在 [EchoFlow 控制台](https://api.echoflowai.cc/console/personal) 注册过账号，并且账户里有余额
- 桌面端已经装好，见 [下载与安装](./install.md)

不再需要提前生成系统访问令牌：登录窗口会直接把你已经登录的站点会话交给桌面端。

## 两条线路：主站与专线

EchoFlow SiHub 有两个入口，账户区域顶部是它们的切换页签：

| 线路 | 地址 | 什么时候选它 |
|---|---|---|
| **主站** | `https://api.echoflowai.cc` | 默认。多数情况下用这条 |
| **专线** | `https://expapi.echoflowai.cc` | 主站不稳或延迟偏高时换这条试试 |

**两条线路各自独立登录，凭据互不覆盖。** 你可以在主站登录一个账号、专线上登录另一个，再分别建渠道。页签上的小圆点是登录状态：绿色表示这条线路已经登录。

## 登录账户

在「设置 → 模型配置」里找到 EchoFlow SiHub 区域，选好线路页签，然后点「**登录 EchoFlow SiHub**」。会弹出一个浏览器窗口，在窗口里完成站点登录即可；登录成功后窗口自动关闭，账户信息回填到面板上。

登录成功后，顶部会显示这条线路的 **用户 ID、用户名、余额和上次刷新时间**。

已经登录过的线路有三个操作：

- **刷新** — 重新拉一次余额和令牌列表。凭据失效时界面会提示重新登录。
- **登录 EchoFlow SiHub** — 凭据过期或应用重启后，重新走一次浏览器登录。
- **解绑** — 清掉这条线路的账户和本机保存的登录状态。**只影响当前选中的线路**，另一条线路不受影响。

### 手动绑定（高级）

没有登录窗口的环境（例如浏览器版、远程桌面）可以展开「**手动绑定（高级）**」，填 **用户 ID** 和**系统访问令牌**：

1. 用户 ID 在控制台个人页面可以复制。
2. 系统访问令牌在控制台的「安全设置 → 系统访问令牌 → 生成令牌」里生成。输入框默认隐藏内容，点右侧的眼睛图标可以查看。

登录状态保存在本机的 `echoflow-account.json`（只有用户 ID 和线路），不会上传；站点凭据只保留在内存和登录窗口自己的存储里。

## 选择令牌并配置渠道

账户登录之后，区域下方会列出这个账户下的调用令牌，每一项显示**令牌名称和脱敏后的 Key 预览**，令牌的额度状态也在里面。

选中一枚令牌会打开统一的详细配置面板——模型、能力、高级参数都在那里设置。**只有点保存时，渠道才会真正出现在下方的模型渠道列表里。** 选错了直接关闭面板就行，不会留下半条记录。

账户下没有可用令牌时，点列表上方的「**创建令牌**」，桌面端会按站点控制台的默认值（无限额度、永不过期）建一枚并直接列出来，选中它就能建渠道。要改额度、改过期时间或看用量，点旁边的「**控制台**」到站点后台处理。

## 令牌和 API Key 的区别

这是最容易混的一处，值得单独说清：

- **系统访问令牌** — 属于账户，用来证明“这个账户是你”。手动绑定、检测账号、读取令牌列表、后续换令牌都靠它。
- **调用令牌（API Key）** — 属于某个具体渠道，真正发出去做模型调用的凭据。

**桌面端默认只显示脱敏的 API Key 预览。** 你选择的是令牌 ID，测试、创建、更新这些动作都由服务端按「账户 + 令牌 ID」完成，并且强制走该令牌所属的端点。配置页提供显式显隐切换；点击显示时才会按账户端点和令牌 ID 单独获取完整 Key。令牌列表仍只返回脱敏预览。
- 给渠道换令牌不需要重新粘贴密钥，换一枚令牌 ID 即可。
- 主站账户的令牌只能建主站渠道，不会串到专线上去。

## 从旧版本升级

旧版本只支持单账户存储，升级后会自动迁移成主站 / 专线两个槽位：原来的账户落在**主站**，专线留空。

如果升级后账户区域看起来是空的，先点一次「刷新」；仍然空的话，说明迁移没有读到旧文件，重新登录或手动绑定一次即可。旧文件 `qingyun-account.json` 只用于迁移读取，新数据一律写进 `echoflow-account.json`。

## 常见问题

**登录窗口关掉了，但账户没出现。** 重新点一次「登录 EchoFlow SiHub」。临时网络故障或本地服务重启会中断一次校验，窗口可能提前关闭；重试即可。反复失败时到「设置 → 诊断」看日志，站点拒绝登录时返回的原因会记在 `bootstrap-rejected` 那一行。

**登录后余额没显示。** 点「刷新」。账户刚登录时余额可能还没同步，界面会显示「尚未同步」。

**提示登录状态已失效。** 点「登录 EchoFlow SiHub」重新登录；用手动绑定的话，回控制台重新生成一枚系统访问令牌，用「更新令牌」换上。

**令牌列表里没有令牌。** 这个账户下还没建过调用令牌。点列表上方的「创建令牌」新建一枚，建好会直接出现在列表里，不需要刷新。

**想改用第三方服务商。** EchoFlow SiHub 和第三方服务商可以并存，在模型渠道列表里随时切换，互不影响。具体见 [连接模型服务](./models.md)。
