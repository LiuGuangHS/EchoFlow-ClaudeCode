# 连接器

连接器让助手直接操作你在第三方服务里的数据——读一份文档、查一个仓库、拉一组表格。它是把外部服务接进会话的入口，不是一个新概念。

入口在侧边栏的「**技能·连接器**」。点开有两大类：

- **服务连接器** — 账号授权型，代表服务本身就是数据源，比如腾讯文档、Notion、GitHub、Airtable。当前收录 **54 个**。
- **工具插件** — 给助手补一套做法或专用技能，比如画架构图、导出 PDF。

左边可以按「目录类型」「服务地区（国内 / 全球）」「服务分类」筛选，也可以直接搜。

## 连接器和技能的区别

这两个入口挨着，最容易混，值得先说清：

| | 连接器 | 技能 |
|---|---|---|
| 是什么 | 一条通往外部服务的通道 | 一套现成的做法或流程 |
| 前提 | **必须完成账号授权** | 装上就能用 |
| 没配好时 | 能力**不会挂到会话上** | 直接可用 |

一句话记法：**连接器是"把门打开"，技能是"给他一本手册"。** 技能本身的说明见 [技能与技能市场](./skills.md)。

有些服务两边都沾：飞书、钉钉、企业微信、微信、QQ、Slack、Telegram、WhatsApp 在这里是**服务连接器**，同时又是 **IM 适配器**（在手机上直接对话的那种）。想从 IM 里用，看 [IM 接入](../im/index.md)；想在会话里读写这些平台的数据，就用这里的连接器。

## 安装与授权

在「技能·连接器」里找到目标服务，点「连接服务」，按提示在浏览器里完成授权。

有一条约束必须记住：**没完成账号授权之前，它的能力不会挂到会话上。** 这是有意的安全设计——装了但没连，模型看不到也调不动，不会出现「以为接上了其实没权限」的情况。列表里这类条目会标成「待连接服务」。

工具插件是另一条路：它们不需要外部账号，装上后要「保存并验证」，让技能包真正加载进来。

## 在会话里引用

`@` 和 `/` 都能引用插件和技能。

会话已经开着的时候去装并连一个连接器，**当前会话会即时刷新出它的技能和工具**，不用重启应用或重开会话。反过来，如果在会话里引用得到但外面列表显示未连接，先回去确认授权是否真的走完了。

## 管理与移除

安装、停用、移除都在同一处，不用去别的地方找。

- **停用** — 保留安装状态，只是不再挂到会话上。
- **移除** — 撤掉这个条目。对工具插件来说，移除会同时删掉它的技能文件，但**已有任务和产出文件不会受影响**。

服务连接器的授权凭据由对应服务掌握，移除条目不会替你撤销对方平台上的授权。要彻底断开，去那个服务的账号设置里取消。

## 常见问题

**图标不显示。** 打包版曾经存在连接器和技能图标加载不出来的问题，0.5.5 已修。仍在旧版本上就先升级。

**装上之后安装不动、一直卡着。** 0.5.6 修过"残留状态阻塞安装"。先移除该条目再重装一次。

**技能显示已加载，但任务里跑不起来。** 加载成功只说明技能包到位了。任务真正需要的 Node.js、命令行工具或其他运行环境还要单独满足——**技能加载成功不代表这些环境已经装好**。

**授权过期了怎么办。** 回到连接器条目重新走一次授权。凭据在各服务自己的有效期内生效，过期后需要重来。
