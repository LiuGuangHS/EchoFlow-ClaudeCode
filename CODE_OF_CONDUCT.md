# Code of Conduct / 行为准则

## Our standard / 基本准则

Treat users, contributors, and maintainers with respect. Discuss ideas and evidence, not personal traits. Be constructive, assume good faith, and protect other people's privacy.

尊重用户、贡献者和维护者；讨论观点与证据，不攻击个人。保持建设性、善意沟通，并保护他人隐私。

## Unacceptable behavior / 不可接受的行为

Harassment, threats, discrimination, sexualized content, deliberate disruption, doxxing, or sharing another person's credentials, private logs, or personal data without permission are not acceptable.

骚扰、威胁、歧视、色情内容、故意破坏讨论、人肉搜索，或未经许可分享他人的凭据、私密日志和个人数据，均不可接受。

## Enforcement / 执行

Maintainers may remove content, lock conversations, or limit participation when needed to keep the project safe and productive. For sensitive conduct concerns, use a private GitHub reporting channel when available rather than a public thread.

维护者可删除内容、锁定讨论或限制参与，以保持项目安全高效。涉及敏感行为问题时，请优先使用可用的 GitHub 私密报告渠道，而不是公开讨论。
